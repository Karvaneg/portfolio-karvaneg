## À propos

Ce dépôt contient le code source de mon portfolio professionnel.  
Il présente une sélection de projets web, des composants UI, ainsi que mes choix techniques en matière d’architecture, d’accessibilité et de design.

---

## Stack technique

- **Next.js** (App Router)
- **React & TypeScript**
- **Tailwind CSS / SCSS**
- Design system & composants réutilisables
- Mise en pratique des principes DevOps :
  - Pipelines **GitLab CI/CD** avec build et déploiement automatisés
  - Analyse de sécurité : SAST et détection de secrets
  - Mirroring Git (GitLab → GitHub)
  - Déploiements automatiques sur **Vercel** (production)
  - Cache et gestion des dépendances via **pnpm** pour des builds reproductibles

---

## Déploiement

Le portfolio est automatiquement déployé sur **Vercel** à chaque push sur la branche `main`.  
Le workflow CI/CD garantit un build sécurisé, reproductible et un déploiement sans intervention manuelle.
